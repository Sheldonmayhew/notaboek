# Contributing to Notaboek

Notaboek is open source, but it isn't open to outside code. It has one maintainer, who writes and merges every change, so pull requests from outside the project are switched off. Bug reports, ideas and questions are all welcome.

## Found a bug

[Open a bug report](https://github.com/Sheldonmayhew/notaboek/issues/new/choose). Search the [open issues](https://github.com/Sheldonmayhew/notaboek/issues) first, in case it's already there.

A good report says what you did, what you expected and what happened instead. If one file causes it, attach it, with anything private taken out. That's often the fastest way to a fix.

## Have an idea

[Start a discussion in Ideas](https://github.com/Sheldonmayhew/notaboek/discussions/categories/ideas). Say what you'd like Notaboek to do and what you do today instead. Others can add to it, and ideas that are picked up become issues.

## Have a question

[Ask in Q&A](https://github.com/Sheldonmayhew/notaboek/discussions/categories/q-a).

## Found a security problem

Don't open an issue. See [SECURITY.md](SECURITY.md) to report it privately.

## Why no pull requests

One author keeps the code consistent and means every line has been read by the person who answers for it. If you've written a fix, describe it in the issue instead. A clear description, or a failing test case, is just as useful as a patch.

The code is [MIT-licensed](LICENSE), so you're free to fork it and change it however you like.
