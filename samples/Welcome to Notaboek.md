# Welcome to Notaboek

Notaboek turns plain `.md` and `.txt` files into pages you'll enjoy writing in. **Everything here is still an ordinary text file**, so it opens anywhere, syncs anywhere and belongs to you.

> [!TIP]
> Press `/` on an empty line to see every block you can add. Click the icon on this callout to change its type.

## Write the way you already do

Markdown shortcuts work as you type, and the marks disappear into formatting:

- Type `#` and a space for a heading, or `##` and `###` for smaller ones
- Type `-` and a space for a bulleted list
  - Press Tab to nest an item
  - Press Shift+Tab to bring it back
- Type `[]` and a space for a to-do

Select any text to get the formatting toolbar: **bold**, *italic*, ~~strikethrough~~, `inline code` and [links](https://example.com).

## Move things around

Hover over a block and use the handle on its left. Drag it to reorder, or click it to change the block's type, duplicate it or delete it.

## Tables and code

| Shortcut | What it does |
| --- | --- |
| `Ctrl+N` | New page |
| `Ctrl+O` | Open a file |
| `Ctrl+Shift+O` | Open a folder |
| `Ctrl+\` | Show or hide the sidebar |
| `Ctrl+/` | Switch between page and source view |
